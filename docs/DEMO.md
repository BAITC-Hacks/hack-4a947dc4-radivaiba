# Защита: 4–5 минут

Перед показом: `docker compose up -d --wait postgres`, затем `npm run demo`, localhost:8080, пароли через `npm run credentials`. Если приложение уже работает в Compose, открыть localhost:8080 без второго сервера. Подключить LLM в .env, перезапустить, проверить отметку AI. Если ключа нет, честно показать резервный режим.

Для чистого старта остановить приложение, создать отдельную пустую PostgreSQL-базу и указать её в DATABASE_URL. При запуске seed загрузится автоматически; предыдущая БД сохранится как резервная копия. Переименование старого state.json не сбрасывает прогресс PostgreSQL.

1. **Проблема, 20 секунд:** разрозненные HR-события не объясняют, как приблизиться к карьерной цели. Здесь обучение связано с требованиями роли.
2. **E0001, 60 секунд:** вход сотрудником, цель Middle, карта навыков. Открыть «Почему этот шаг»: цель/грейд, численный разрыв, история. Показать ожидаемый прирост.
3. **Обновление, 30 секунд:** «Отметить выполнено», навыки и прогресс меняются. Новые рекомендации и запись в истории. Повторный запрос не начисляет прирост ещё раз.
4. **Смена роли, 40 секунд:** HR → поиск E0004 → переход Data Analyst → Product Manager. Логика не привязана к ID.
5. **Профиль жюри, 60 секунд:** «Загрузить данные», JSON и CSV в исходной схеме. Новый профиль сразу доступен через поиск и получает расчёт.
6. **HR, 40 секунд:** дефициты, люди без доступного шага, участие. Нет случайных рекомендаций для заполнения пустоты.

## Ответы на вопросы

- Почему не самый слабый навык? Критичность для цели, фактический прирост, ограничения, история участия и длительность.
- Что делает LLM? Выбирает и объясняет шаги из разрешённых кандидатов. Не считает навыки и не создаёт события.
- Если интернет пропадёт? После установки зависимостей UI и резервный алгоритм работают локально.
- Где геймификация? Видимая траектория и результат каждого шага; обязательное ядро важнее баллов.
- Почему дата 2026-10-01? Это срез организаторов, а не текущее время компьютера.

Границы: синтетическое локальное демо, две роли, один сервер. Завершение не проверяет реальное прохождение. Навыки не гарантируют повышения. Текст LLM зависит от модели, численные подтверждения показаны отдельно.
