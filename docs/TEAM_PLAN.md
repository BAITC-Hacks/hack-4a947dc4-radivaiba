## Получение своей ветки

```powershell
git clone https://github.com/BAITC-Hacks/hack-4a947dc4-radivaiba.git
cd hack-4a947dc4-radivaiba
git fetch origin
git switch --track origin/codex/frontend
# Или codex/backend / codex/ai-engine
npm run setup -- --data-dir "C:\папка\стартового-набора"
npm run dev
```

Отдельный клон у каждого. Стартовые данные — из набора организаторов, не через GitHub.

P0: воспроизводимость, импорт произвольного профиля, правильный прогресс, три фактора и права. P1: настоящая LLM, качество выбора и демо. P2: визуальные детали. После 3:15 не добавлять функции.

Не тратить время на баллы, магазин, SSO, PostgreSQL, чат и deploy. Если LLM медленная — выбрать доступную быструю модель/сократить промпт; не маскировать fallback как AI. Перед защитой заморозить общий коммит codex/mvp, проверить npm run demo и записать SHA.
