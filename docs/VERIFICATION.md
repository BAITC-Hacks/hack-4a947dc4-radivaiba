В браузерном прогоне E0001 завершил System Design Fundamentals: прогресс вырос с 62.2% до 71.1%, критический разрыв закрылся. Тестовые изменения выполнялись в отдельном `tmp/qa-state.json`, а не в исходном стартовом наборе.

Первоначальная блокировка одного Go-теста Windows Application Control не воспроизвелась после исправления кода и пересборки; окончательный полный запуск прошёл. Docker сначала был недоступен в ограниченной среде инструментов, но проверка с доступом к Docker Desktop прошла.

## Повторить сквозную API-проверку

Использовать отдельное тестовое состояние, поскольку сценарий завершает активности и добавляет синтетические профили.

```powershell
# Терминал 1, корень репозитория
$env:PORT='8081'
$env:STATE_PATH='tmp/qa-state.json'
$env:DEMO_EMPLOYEE_PASSWORD='qa-employee'
$env:DEMO_HR_PASSWORD='qa-hr'
$env:LLM_API_KEY=''
npm run demo

# Терминал 2
$env:QA_BASE_URL='http://127.0.0.1:8081'
$env:QA_EMPLOYEE_PASSWORD='qa-employee'
$env:QA_HR_PASSWORD='qa-hr'
node scripts/smoke.mjs
```

Тестовые пароли выше предназначены только для отдельного QA-процесса. Обычный setup генерирует случайные локальные пароли. Данные организаторов, runtime, .env и временные профили исключены из Git.
